## 一、查看文件与目录权限

| 命令           | 说明                             | 示例                             |
| :------------- | :------------------------------- | :------------------------------- |
| `ls -l <文件>` | 长格式显示，第一字段为权限       | `ls -l script.sh` → `-rwxr-xr--` |
| `stat <文件>`  | 显示详细权限（含数字权限如 755） | `stat /etc/passwd`               |

**权限字段解读**（以 `-rwxr-xr--` 为例）：

- 第1字符：`-` 普通文件，`d` 目录，`l` 符号链接
- 第2-4字符：所有者权限（r/w/x）
- 第5-7字符：组用户权限
- 第8-10字符：其他用户权限

**文件与目录的默认权限差异**：

- 文件基础权限 = `666`（无执行权限 x）
- 目录基础权限 = `777`（有执行权限 x，否则无法 `cd` 进入）

## 二、umask – 控制新文件/目录的默认权限

### 基本用法

| 命令        | 说明                                     |
| :---------- | :--------------------------------------- |
| `umask`     | 查看当前掩码（八进制）                   |
| `umask -S`  | 查看符号形式掩码（如 `u=rwx,g=rx,o=rx`） |
| `umask 027` | 临时设置掩码（仅当前 shell）             |

### 永久设置

将 `umask 022` 写入 `~/.bashrc`、`~/.profile` 或 `/etc/profile`。

### 计算示例（基础权限 - umask）

| 类型 | 基础权限 | umask | 实际权限        | 说明                           |
| :--- | :------- | :---- | :-------------- | :----------------------------- |
| 文件 | 666      | 022   | 644 (rw-r--r--) | 组和其他只读                   |
| 文件 | 666      | 027   | 640 (rw-r-----) | 组可读，其他无                 |
| 目录 | 777      | 022   | 755 (rwxr-xr-x) | 所有者全权，组和其他可读可执行 |
| 目录 | 777      | 027   | 750 (rwxr-x---) | 组可读可执行，其他无           |

### 常用 umask 值

| umask | 文件权限 | 目录权限 | 适用场景                 |
| :---- | :------- | :------- | :----------------------- |
| 002   | 664      | 775      | 同组可写                 |
| 022   | 644      | 755      | 默认安全（组和其他只读） |
| 027   | 640      | 750      | 同组可读，其他不可访问   |
| 077   | 600      | 700      | 仅所有者完全权限         |

## 三、用户与组管理命令

### 1. 查看用户/组信息

| 需求               | 命令                               | 示例 |
| :----------------- | :--------------------------------- | :--- |
| 查看所有组         | `cat /etc/group` 或 `getent group` |      |
| 查看所有组ID       | `getent group | cut -d: -f3`       |      |
| 查看当前用户所属组 | `groups`                           |      |
| 查看指定用户所属组 | `groups username` 或 `id username` |      |
| 查看用户完整ID信息 | `id` / `id username`               |      |
| 只显示所有组ID     | `id -G username`                   |      |
| 只显示所有组名称   | `id -nG username`                  |      |

### 2. 常用 `useradd` 参数（推荐掌握）

| 参数               | 作用                       |
| :----------------- | :------------------------- |
| `-m`               | 创建家目录                 |
| `-s /bin/bash`     | 指定登录 Shell             |
| `-G group1,group2` | 指定附加组（组需提前存在） |
| `-g primary_group` | 指定主组（默认创建同名组） |
| `-c "comment"`     | 添加用户描述               |
| `-u 1501`          | 指定 UID                   |
| `-r`               | 创建系统用户               |

#### 工作选择建议

| 场景                           | 推荐命令  | 原因                 |
| :----------------------------- | :-------- | :------------------- |
| 手工少量创建（Debian/Ubuntu）  | `adduser` | 交互式，不易遗漏参数 |
| 脚本批量创建 / CentOS / 跨平台 | `useradd` | 参数化、行为统一     |





### 3. 创建用户时指定组的注意事项

| 场景                                       | 是否需要提前创建组 | 说明                       |
| :----------------------------------------- | :----------------- | :------------------------- |
| 不指定 `-g`（使用默认行为）                | **否**             | 系统自动创建同名组作为主组 |
| 用 `-g` 指定其他组作为**主组**             | **是**             | 该组必须已存在             |
| 用 `-G` 或 `--extra-groups` 指定**附加组** | **是**             | 所有列出的组都必须已存在   |





### 4. 用户组管理（`addgroup` / `groupadd`）

| 操作        | Debian/Ubuntu                        | CentOS/RHEL（通用）               |
| :---------- | :----------------------------------- | :-------------------------------- |
| 创建普通组  | `sudo addgroup groupname`            | `sudo groupadd groupname`         |
| 创建系统组  | `sudo addgroup --system groupname`   | `sudo groupadd -r groupname`      |
| 指定GID创建 | `sudo addgroup --gid 2000 groupname` | `sudo groupadd -g 2000 groupname` |
| 删除组      | `sudo groupdel groupname`            | 同上（组不能是任何用户的主组）    |



### 5. 用户修改与维护

| 操作                     | 命令示例                                                     |
| :----------------------- | :----------------------------------------------------------- |
| 将现有用户加入附加组     | `sudo usermod -aG docker john`（`-a` 必须与 `-G` 同用，避免覆盖） |
| 修改用户主组             | `sudo usermod -g developers john`                            |
| 设置/修改用户密码        | `sudo passwd john`                                           |
| 查看用户密码状态         | `sudo passwd -S john`                                        |
| 一行命令创建并设初始密码 | `useradd -m username && echo "username:pass" | chpasswd`     |
| 删除用户及家目录         | `sudo userdel -r username`                                   |
| 锁定用户                 | `sudo usermod -L username`                                   |
| 解锁用户                 | `sudo usermod -U username`                                   |

> **注意**：修改用户的组关系后，用户必须**重新登录**才能生效。

## 四、快速参考卡片

```
# ----- 权限相关 -----
ls -l file
stat file
umask                     # 查看掩码
umask 027                 # 设置掩码
umask -S                  # 符号形式

# ----- 查看用户/组 -----
id username
groups username
getent group              # 查看所有组
getent passwd             # 查看所有用户

# ----- 创建用户（通用风格）-----
sudo useradd -m -s /bin/bash -G group1,group2 username
sudo passwd username

# ----- 创建用户（Debian/Ubuntu 交互式）-----
sudo adduser username

# ----- 组管理 -----
sudo groupadd groupname
sudo groupdel groupname
sudo usermod -aG groupname username   # 将用户加入附加组

# ----- 删除用户 -----
sudo userdel -r username
```
